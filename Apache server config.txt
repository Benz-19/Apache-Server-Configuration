Steps to configure the Apache server

NOTE: OPEN the cmd as an administrator


===============================
1. Open:
===============================
C:\wamp64\bin\apache\apache2.x.x\conf\httpd.conf


================================
2. Uncomment on these two lines:
================================
LoadModule vhost_alias_module modules/mod_vhost_alias.so
Include conf/extra/httpd-vhosts.conf


================================
3. Configure Virtual Hosts:
================================

Visit this path: C:\Windows\System32\drivers\etc

Next add the local virtual site you want to host:

<VirtualHost *:80>
    ServerName genealogy.local
    DocumentRoot "C:/wamp64/www/Genealogy/public"

    <Directory "C:/wamp64/www/Genealogy/public">
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>


==============================
4. Edit Hosts File:
==============================
open:
C:\Windows\System32\drivers\etc\hosts

next, add:
127.0.0.1 genealogy.local
